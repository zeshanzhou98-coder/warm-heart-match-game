## 🏗 项目结构

```
├── index.html          # 主页面
├── styles.css          # 样式表（独立文件，利于缓存）
├── app.js              # 主程序逻辑（独立文件，利于缓存）
├── sw.js               # Service Worker（PWA离线支持）
├── manifest.json       # PWA配置
├── README.md           # 项目说明
└── assets/             # 静态资源
    ├── avatar.jpg      # 默认头像
    ├── bg.jpg          # 默认背景
    ├── icon-192.png    # PWA图标
    ├── apple-touch-icon.png
    ├── menu-*.jpg      # 导航菜单图标
    ├── cal-*.jpg       # 日历背景图
    └── exercise.jpg    # 锻炼模块图片
```

## 🔧 优化说明

相比原始版本，本项目进行了以下优化：

1. **代码分离** - CSS/JS从HTML中分离为独立文件，利于浏览器缓存
2. **移除第三方追踪** - 去掉了腾讯分析脚本，保护隐私
3. **PWA支持** - 完整的Service Worker配置，支持离线访问
4. **Gzip压缩** - GitHub Pages自动启用gzip，加载更快
5. **响应式设计** - 完美适配桌面端和移动端

## 💡 技术栈

- 纯 HTML/CSS/JavaScript，无框架依赖
- LocalStorage 本地数据持久化
- Service Worker 离线缓存
- SVG 内联矢量图标（角落生物角色）
